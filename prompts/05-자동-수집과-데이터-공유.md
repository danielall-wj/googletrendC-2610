# 5단계. 2시간 자동 수집과 데이터 공유

```text
앞서 비교한 방식 중 선택한 구조를 사용해 한국 Google Trends를 2시간마다 자동 수집하도록 만들어 주세요.

Mac과 Windows에서의 동작을 각각 설명하고 다음을 처리해 주세요.
- 자동 수집 설정과 해제
- 수집 성공·실패 확인
- 실행이 지연되거나 누락됐을 때의 동작
- PC가 꺼져 있거나 절전 중일 때의 동작
- Mac과 Windows 간 데이터 공유 여부와 방법
- 데이터의 공개 범위와 접근 권한
- 외부 서비스를 이용한다면 무료 사용 한도와 비용 가능성

가능한 설정과 테스트를 직접 수행해 주세요. 계정 연결이나 비밀키 등록 등 제가 직접 해야 하는 작업과 아직 검증하지 못한 사항은 구분해서 알려 주세요.
```
