# 1단계. 요구사항과 개발 환경 설계

```text
한국 Google Trends 데이터를 수집하고 확인하는 도구를 처음부터 새 프로젝트로 만들고 싶습니다.

개발과 사용 환경은 macOS와 Windows입니다. 어느 운영체제에서도 프로젝트를 설정하고 개발할 수 있어야 하며, 최종적으로 각각의 설치형 앱을 만들고 싶습니다.

목표:
- 한국의 인기 검색어를 수집합니다.
- 2시간마다 자동 수집합니다.
- 최신 검색어와 과거 수집 기록을 확인합니다.
- Mac과 Windows에서 사용하기 쉽도록 만듭니다.

먼저 코드를 작성하지 말고 다음을 조사하고 설계해 주세요.

1. 현재 사용할 수 있는 한국 Google Trends 데이터 수집 방법, 접근 조건, 수집 가능한 정보
2. 수집 방법별 요청 제한, 안정성, 비용 가능성
3. 공식적으로 제공되지 않는 기능에 의존하는 부분
4. Mac과 Windows에서 모두 개발·실행할 수 있는 기술 구성
5. 각 PC에서 직접 수집하는 방식과 외부에서 수집하는 방식의 비교
6. 두 PC 간 데이터 공유 방법과 각 방식의 비용·설정 난이도
7. 운영체제별 설치 파일 생성 및 배포 방법
8. 단계별 구현과 검증 계획

공식 자료를 우선 확인하고, 확인된 사실과 추정을 구분해 주세요. 선택이 필요한 사항은 추천안과 이유를 알려 주세요.
```
