# 4단계. 대시보드 만들기

```text
수집한 한국 Google Trends 데이터를 확인할 대시보드를 만들어 주세요. macOS와 Windows에서 모두 개발·실행할 수 있어야 합니다.

다음 기능을 포함해 주세요.
- 인기 검색어 목록과 검색
- 제공 가능한 기준에 따른 정렬
- 실제 제공되는 검색량과 관련 정보
- 검색어별 상세 정보
- 마지막 수집 시각과 수집 상태
- 과거 수집 기록 조회
- CSV 다운로드

데이터가 없거나 오래된 경우 화면에 표시하고, 수집하지 않은 정보는 만들어 표시하지 마세요.

현재 환경에서 화면을 실행해 주요 기능을 확인하고, Mac과 Windows의 실행 방법을 각각 문서화해 주세요.
```
