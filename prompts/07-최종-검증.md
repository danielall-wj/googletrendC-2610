# 7단계. 최종 검증

```text
완성된 한국 Google Trends 도구를 Mac과 Windows 사용자 관점에서 전체 점검해 주세요.

다음을 확인해 주세요.
- 각 운영체제의 개발 환경 설정과 앱 실행
- 한국 트렌드 수집과 저장
- 2시간 자동 수집 및 실패 확인
- 최신 데이터와 과거 기록 조회
- 검색, 정렬, CSV 다운로드
- 앱 재실행과 인터넷 연결 실패 시 동작
- Mac과 Windows 설치 파일 생성 및 설치

현재 환경에서 가능한 테스트를 직접 실행하고, 발견한 문제는 수정한 뒤 다시 검증해 주세요. 실제 확인한 결과와 아직 확인하지 못한 결과를 구분하고, 제가 Mac과 Windows에서 각각 직접 확인할 항목을 짧은 체크리스트로 정리해 주세요.
```
