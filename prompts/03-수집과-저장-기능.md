# 3단계. 수집과 저장 기능 구현

```text
수집 시험 결과를 바탕으로 한국 Google Trends 데이터를 수집하고 저장하는 프로그램을 만들어 주세요.

- macOS와 Windows에서 실행할 수 있어야 합니다.
- 한국 인기 검색어와 실제 제공되는 관련 정보를 수집합니다.
- 수집 시각과 원본 데이터를 보관합니다.
- 과거 수집 기록을 조회할 수 있도록 저장합니다.
- 중복 데이터는 기준을 정해 처리합니다.
- 수집 실패 시 기존 데이터를 보존하고 오류를 기록합니다.

운영체제별 개발 환경 설정, 수동 수집 명령, 데이터 저장 위치를 문서화해 주세요. 현재 환경에서 실제 수집과 저장을 실행해 검증하고, 다른 운영체제에서 확인이 필요한 항목은 명시해 주세요.
```
