# 6단계. Mac·Windows 설치형 앱 만들기

```text
완성된 한국 트렌드 도구를 macOS와 Windows용 설치형 데스크톱 앱으로 만들어 주세요.

- 운영체제별로 앱을 설치하고 실행할 수 있어야 합니다.
- 앱에서 최신 데이터와 과거 기록을 볼 수 있어야 합니다.
- 데이터 연결에 실패하면 오류와 마지막 갱신 시각을 표시합니다.
- 기존 수집과 자동화 기능은 설계한 방식대로 유지합니다.

Mac과 Windows 각각의 개발·빌드·설치 방법을 문서화해 주세요. 가능하면 GitHub Actions에서 두 운영체제용 설치 파일을 생성하도록 구성해 주세요.

현재 환경에서 가능한 빌드와 실행은 직접 검증하고, 다른 운영체제에서 아직 확인하지 못한 사항은 명확히 알려 주세요. 코드 서명 없이 시험 설치할 때의 제약과 정식 배포에 필요한 준비 사항도 설명해 주세요.
```
