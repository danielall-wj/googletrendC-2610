# 2단계. 한국 데이터 수집 시험

```text
앞서 조사한 방법을 바탕으로 한국 Google Trends 데이터를 실제로 가져올 수 있는지 시험해 주세요.

시험 코드는 macOS와 Windows에서 모두 실행할 수 있도록 작성하고, 운영체제별 환경 설정과 실행 명령을 알려 주세요.

다음을 확인해 주세요.
- 한국 인기 검색어를 가져올 수 있는지
- 검색어별로 어떤 정보가 제공되는지
- 데이터의 기준 시각과 수집 시각을 알 수 있는지
- 요청 실패, 제한, 데이터 누락 가능성이 있는지

현재 작업 중인 운영체제에서는 직접 실행해 검증해 주세요. 다른 운영체제에서 아직 확인하지 못한 부분은 따로 밝혀 주세요. 실제로 제공되지 않은 데이터는 만들어 넣지 마세요.
```
